    Templating guide

    Wrap a variable in double curly braces — {{ variable }} — in the subject, body, CC, or BCC. Every recipient receives their own personalized copy.

    Available variables

      How to set values

      • {{ email }} is always the recipient's address.
      • Type Name <email@example.com> in the recipient list to set {{ name }}.
      • Import a CSV with an Email column (optionally a Name column). Every other column becomes a custom variable — headers are lowercased and spaces become underscores, e.g. Company Name → {{ company_name }}.
      • Import a JSON array of objects (or paste one into the recipients box), e.g. [{"email":"a@x.com","name":"A","company":"Acme"}]. email/name are recognized; other keys become variables.
